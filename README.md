A. Identitas Produk Perangkat Lunak
1. Nama Aplikasi / Software: Saung Sambal 
2. Kategori Produk: Aplikasi Pemesanan Berbasis Web
3. Deskripsi Singkat Fungsi Aplikasi:
Saung Sambal adalah web pemesanan digital yang di rancang untuk membantu
pedagang UMKM dalam pemesanan agar lebih cepat dan tidak menimbulkan anteran
yang panjang.
